💸 App de Controle de Gastos (React Native)
📌 Sobre o projeto

Este é um aplicativo mobile simples de controle de gastos domésticos, desenvolvido como parte do meu aprendizado em React Native.

A aplicação permite adicionar gastos e visualizar um resumo em outra tela. Esta é uma primeira versão (MVP), com foco em entender conceitos básicos de desenvolvimento mobile utilizando React Native e Expo.

🚀 Funcionalidades
➕ Adicionar novos gastos
📊 Visualizar lista/resumo de gastos
🔄 Navegação entre telas
🛠️ Tecnologias utilizadas
React Native
Expo
📱 Como funciona

O app possui duas telas principais:

Tela de adicionar gasto
O usuário insere informações de um gasto
Tela de resumo
Exibe os gastos adicionados durante o uso do app

⚠️ Observação:
Os dados ainda não são persistidos. Ou seja, ao fechar o app, as informações são perdidas.

⚙️ Como executar o projeto
Clone o repositório:
git clone <URL_DO_REPOSITORIO>
Acesse a pasta:
cd nome-do-projeto
Instale as dependências:
npm install
Inicie o projeto:
npx expo start
Execute no dispositivo:
Use o app Expo Go no celular
ou
Execute em um emulador
